## What the model contains
- Input section with all 7 variables (editable)
- Auto-calculated outputs using formulas
- Gross Margin, Amazon Fee, Ad Cost per Unit
- Net Margin for Ad and Organic units
- Total Monthly Revenue and Profit
- ACOS % and TACOS %
- All formulas linked — change any input and outputs update automatically

## How to use
1. Open the Google Sheet
2. Change any value in Column B
3. All outputs in Column E update automatically
4. Test scenarios by changing Ad Spend, Units, or COGS
